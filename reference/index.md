# Reference

Use this section for stable user-facing contracts.

- [Configuration](/reference/configuration): config hierarchy, defaults, required
  fields, allowed values, profiles, platform auth, and environment overrides.
- [CLI](/reference/cli): installation, commands, flags, environment inputs, outputs, and
  examples.
- [Findings schema](/reference/findings-schema): canonical findings bundle and
  compatibility expectations.
- [Artifacts](/reference/artifacts): public output paths, formats, creation conditions,
  consumers, and retention advice.
- [Exit behavior](/reference/exit-behavior): success, blocking, setup, provider, diff,
  publishing, and gate behavior.
- [Versioning](/reference/versioning): CLI/package, config, and artifact compatibility.
- [Support matrix](/reference/support-matrix): supported hosts, publishers, feedback
  surfaces, provider types, and stability.
- [Glossary](/reference/glossary): concise definitions of terms used across the
  documentation.
